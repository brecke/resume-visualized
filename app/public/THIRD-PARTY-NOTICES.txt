Build tooling and browser helper

The pinned direct development dependencies are Vite 8.3.4 (MIT),
TypeScript 7.0.2 (Apache-2.0), and @types/node 24.19.1 (MIT).
The pinned runtime/toolchain is Node 24.21.0 and npm 12.2.0.
There are no declared production npm dependencies. Node, npm, TypeScript,
and Node type definitions are build/test tools, not deployed browser runtimes.
Their full distribution notices remain with their respective installations.

Vite's default production configuration enables its modulepreload polyfill.
The installed Vite implementation delegates the bundled-build helper to
Rolldown 1.2.13 (MIT). The Vite and Rolldown core grants are retained below
for browser code emitted by this toolchain. This is not an exhaustive legal
audit of the toolchain's own bundled/transitive dependencies: Vite's installed
LICENSE.md separately lists Apache-2.0, BSD-2-Clause, CC0-1.0, ISC, and MIT
licenses for its bundled build-tool dependencies; Rolldown's LICENSE refers
to its upstream THIRD-PARTY-LICENSE. Those build-tool distributions are not
copied wholesale into this static site.
